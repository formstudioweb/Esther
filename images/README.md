# ESTHER — сайт для GitHub Pages

## Публікація
1. Створіть новий публічний репозиторій.
2. Завантажте в корінь репозиторію всі файли та папку `images`.
3. Відкрийте **Settings → Pages**.
4. У **Build and deployment** оберіть **Deploy from a branch**.
5. Виберіть гілку `main` і папку `/root`, після чого натисніть **Save**.

## Контакти
Посилання на Instagram уже підключене: `https://www.instagram.com/now.esther`.

## Редагування
- Основний текст: `index.html`
- Кольори та дизайн: `style.css`, блок `:root`
- Інтерактивність: `script.js`
